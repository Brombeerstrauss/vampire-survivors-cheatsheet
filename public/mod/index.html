Vampire Survivors mod: evolution overlay, level-up grades and minimap

VS Cheatsheet Bridge is a free, open-source mod for Vampire Survivors on Steam. It is a BepInEx 6 (IL2CPP) plugin that shows inside the game what each weapon still needs to evolve, grades the weapons and items on the level-up screen for your character and build, and adds a small minimap. It runs on Windows and on the Steam Deck (Proton), in English and German, also in co-op.

Features

  • Evolution overlay with the game's own images: for every weapon the ingredients of its next evolution, what is missing, which level is still needed ("Needed to evolve") and when the next chest brings the evolution. Unions, gifts, morphs and DLC evolutions are included, up to two steps ahead.
  • Level-up grades from A+ to D: each card on the level-up screen is graded for your character, your current weapons and items, the evolutions you are building, community tier lists and your free slots. Evolution partners come first, clear advice from the wiki against an item for your character comes last.
  • Minimap: stage items, relics, chests, small pickups, enemies as red dots and bosses with their own image, around you. On stages with a map picture (as in the pause menu, e.g. after picking up the stage's map) the minimap shows that picture behind the symbols. Drag it with the mouse, choose what it shows in its menu (F7), change size and range.
  • Keys: F8 switches between overlay and minimap, overlay only, minimap only and nothing; F9 resets the positions; F7 opens the minimap's menu. On the Steam Deck, bind them to the back buttons in Steam Input.
  • Co-op: one block per player in the overlay; in online co-op the minimap follows your own character.
  • Companion app: the mod can pass your run to the free Vampire Survivors Cheatsheet web app (evolutions, run tracker, recommendations for all characters and DLCs).

Requirements

  • Vampire Survivors 1.16 (Steam, Windows version; on the Steam Deck through Proton)
  • BepInEx 6.0.0-be.788, package BepInEx-Unity.IL2CPP-win-x64. Older MelonLoader guides no longer apply since game version 1.16.

Download and install

  1. Extract BepInEx into the game folder (where VampireSurvivors.exe is) and start the game once. On the Steam Deck also set the launch option WINEDLLOVERRIDES="winhttp=n,b" %command%.
  2. Get the plugin from the releases page and extract the ZIP into the game folder, or build it yourself: on Windows with dotnet build, on Linux and the Steam Deck with mod/build-linux.sh.
  3. Start a run: the overlay and the minimap appear.

Step-by-step guide, all settings and troubleshooting: mod documentation on GitHub. Source code: GitHub repository (MIT license).

Is it safe?

The mod only reads the game: it changes no stats, items or save files. It is meant for single player and co-op with friends. The minimap shows things the game's own map only shows with the Milky Way Map relic; turn it off in the settings if that feels like cheating.
